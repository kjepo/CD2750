# CD2750 Programspråkssemantik

Kursmaterial från kursen CD2750 Programspråkssemantik (senare CD5140) som jag
(Kjell Post) gav vid Mälardalens högskola under andra halvan av 1990-talet.
Kursen behandlade olika sätt att definiera semantik (betydelse) för
programmeringsspråk – operationell semantik, denotationssemantik och axiomatisk
semantik – tillsammans med λ-kalkyl, domänteori och statisk analys. På
laborationerna implementerades semantikdefinitionerna i det funktionella
språket Gofer.

Originalen skrevs i LaTeX 2.09 med Latin-1-kodning och har 2026 konverterats
till LaTeX2e/UTF-8 och samlats i några få PDF-filer. Innehållet är i övrigt
oförändrat, så datum, programversioner och praktiska detaljer speglar kursen
som den var då.
